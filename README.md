# Sudoku SAT Solver

Encodes Sudoku (`N x N`, `N = box_size²`) as CNF with several at-most-one (AMO)
encodings, solves it with PySAT solvers, and compares against ILP/CP baselines
(CP-SAT, Gurobi, CPLEX MIP, CPLEX CP, CBC).

## Install and run

Python **3.12 or 3.13** is recommended. The environment used for the benchmark
(Python and library versions, CPU, platform) is recorded in `results/meta.json`.

```bash
python3 -m venv .venv && source .venv/bin/activate
python3 -m pip install -r requirements.txt
```

`requirements.txt` holds the core dependencies: PySAT (the command-line solver
and the SAT benchmarks), `ortools` (CP-SAT baseline), `pytest`, `matplotlib`
and `pandas` (plots). Optional baselines are installed separately:

```bash
python3 -m pip install -r requirements-extra.txt   # gurobipy, cplex, docplex, pulp (CBC)
```

**Free-edition limits.** The pip editions of Gurobi and CPLEX are free but
limit the model size, so larger grids exceed what they accept. The benchmark
records those runs as `status = license_limit` (not as a solver failure, and not
as a time), and the tables mark them "licence cap". A baseline whose library is
not installed is recorded as `missing_library` and its tests are skipped. A full
academic or commercial licence removes the cap.

From the repository root, solve the included example:

```bash
python3 main.py data/puzzles/example_9x9.suk --box 3
```

The command prints encoding statistics followed by the solved grid, or
`UNSATISFIABLE` for an inconsistent puzzle. A missing puzzle path is reported
as a CLI error. `python3 main.py --help` shows the supported CLI options.

### Command-line options

- `--box N`: box size; 3 gives 9x9, 4 gives 16x16, 5 gives 25x25 (1 to 5 are supported by the puzzle file format).
- `--amo NAME`: AMO encoding, default `pairwise` (see the list below).
- `--solver NAME`: PySAT solver, default `cadical195`. The benchmark uses
  `cadical195`, `glucose42`, `kissat404` and `minisat22`.
- `--check-unique`: after solving, check whether the solution is unique.
- `--no-unit-alo`: drop the redundant "at least once" clauses of rows, columns and boxes.

```bash
python3 main.py data/puzzles/example_9x9.suk --box 3 --amo product
python3 main.py data/puzzles/example_9x9.suk --box 3 --check-unique
python3 main.py data/puzzles/example_9x9.suk --box 3 --no-unit-alo
```

`--check-unique` adds a blocking clause over the cell variables `var(r,c,v)` and
solves again on the same solver instance. If the second call is UNSAT the
solution is unique; otherwise a second solution is printed. The verdict does not
depend on the AMO encoding because auxiliary variables are not blocked.

`--no-unit-alo` removes the clauses saying each value appears at least once in
every row, column and box. They are logically redundant given the cell and AMO
clauses; the per-cell "at least one value" clause is always kept. The benchmark
uses this flag for its ablation experiment.

### AMO encodings

Eight encodings are available through `--amo` and `AMO_ENCODERS` in
`src/encodings/amo.py`:

`pairwise`, `sequential`, `commander`, `binary`, `product`,
`pysat_seqcounter`, `pysat_bitwise`, `pysat_ladder`.

The first five are implemented in this repository. The three `pysat_*` entries
are the same families as generated by the PySAT library, included for comparison
with the hand-written versions.

### Tests

```bash
python3 -m pytest -q src/tests
```

The tests cover every AMO encoding exhaustively over group sizes, end-to-end
solving with every encoding, the uniqueness check, input validation,
`--no-unit-alo`, puzzle I/O and the baselines (a baseline whose library is not
installed is skipped, not failed).

### Puzzle files

Puzzle files contain exactly `N²` non-whitespace cells in row-major order,
where `N = box_size²`. Use `.` for an empty cell (`0` is accepted as a legacy
empty-cell marker). Values 1–9 are written as `1`–`9`; values 10–35 use
lowercase `a`–`z` (base 36). The supported grid sizes are 1×1, 4×4, 9×9,
16×16, and 25×25; `--box` must be from 1 through 5. Cell values in a
serialized solution use the same symbols, with `.` representing an empty cell.
The text format limit does not apply to the encoder itself: the benchmark also
encodes larger grids (up to 64×64) without saving them as files.

## Reproducible benchmark

```bash
python3 -m src.benchmark --boxes 3 4 5 6 --puzzles 3 --timeout 60 --out results/results.csv
python3 -m src.benchmark --only size --out results/results.csv
```

Experiments (selected with `--only`, default `sat ablation baseline`):

- `sat`: every AMO encoding × every usable PySAT solver, per grid size.
- `ablation`: with and without the unit "at least once" clauses.
- `baseline`: CP-SAT, Gurobi, CPLEX MIP, CPLEX CP and CBC. CP-SAT and the other
  baselines are pinned to one thread to match the single-threaded SAT solvers.
- `size`: encoding size only (variables, clauses, build time) up to 64×64,
  without solving. `pairwise` is skipped at the largest sizes because the clause
  list does not fit in memory.

Puzzles are generated from fixed seeds (`box * 1000 + puzzle index`) and
punctured at a 0.4 keep ratio by default (`--keep-ratio`). A punctured grid is
guaranteed to have at least the generated completion, but is **not guaranteed to
have a unique solution**. This is acceptable for measuring solve time; use
`--check-unique` to test a particular puzzle.

Every job runs in its own process so a hard instance can be killed at the time
limit. Rows are appended to the CSV as soon as they finish, and re-running the
same command with the same `--out` skips jobs already present (resume). Note that
`missing_library` rows count as done: after installing an extra library, delete
those rows from the CSV before re-running so the jobs are repeated.

The CSV records, per run: experiment, method, solver, `unit_alo`, box and grid
size, puzzle index, keep ratio, variable and clause counts, `t_encode`,
`t_solve`, `t_total`, status (`solved`, `timeout`, `license_limit`,
`missing_library`, `encoded`, ...) and whether the solution was independently
verified (`valid`). A timeout row is plotted at the time limit; the extra seconds
in a raw timeout row are only the harness's kill margin.

`results/meta.json` is appended on each invocation with the command, parameters,
Python and library versions, CPU count, platform, which SAT solvers were usable,
and the content hash of every puzzle. Puzzles up to 25×25 are also saved in
`results/instances/`. PySAT solvers that cannot be built are recorded there and
skipped rather than failing the run.

Check the data and regenerate the figures and tables from the CSV, without
running any solver:

```bash
python3 -m src.plot_results --csv results/results.csv --out results --audit
python3 -m src.plot_results --csv results/results.csv --out results
```

`--audit` checks the CSV schema, duplicate job keys, unknown statuses, timing
consistency, that every `solved` row has `valid=True`, and that the saved
puzzles match `meta.json` and regenerate from their seeds; it exits with code 1
on any failure. The second command writes `results/figures/` (PDF and PNG) and
`results/tables/` (CSV and LaTeX). It does not modify the raw CSV, and no result
is hard-coded in the script. The measured results and their discussion are in
`results/` and `report/`.

## Repository layout

```
main.py                      # command-line entry point
requirements.txt             # core dependencies
requirements-extra.txt       # optional Gurobi / CPLEX / CBC (free editions are size-limited)
src/
  main.py                    # CLI implementation
  sudoku_encoder.py          # Sudoku -> CNF (amo_method, unit_alo)
  solver.py                  # PySAT solving and uniqueness check
  puzzle_io.py               # puzzle I/O, grid generation, puncturing, solution check
  benchmark.py               # benchmark harness (one process per job, resume)
  plot_results.py            # figures, tables and --audit
  encodings/                 # alo.py, amo.py (8 AMO encodings)
  baselines/                 # CP-SAT, Gurobi, CPLEX MIP, CPLEX CP, CBC
  tests/                     # pytest suite
data/puzzles/                # example puzzle
results/                     # results.csv, meta.json, instances/, figures/, tables/
report/                      # LaTeX sources of the report
```
